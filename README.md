**✨ About the Project**

Engagement Invitation is a personalized digital invitation website developed for my sister's engagement ceremony.

Instead of a traditional invitation alone, this project brings the celebration online through an elegant and interactive web experience.

The goal was simple: create something memorable, beautiful, and personal for one of the most special moments in our family.

**🎯 Project Highlights**

- 💍 Personalized digital engagement invitation.
- 🎨 Elegant and visually appealing user interface.
- 📱 Responsive web experience across devices.
- ✨ Smooth animations and interactive visual elements.
- ❤️ Designed with a personal touch to celebrate a special occasion.

🛠️ Tech Stack**

🚀 Getting Started

Follow these steps to run the project locally.

1. Clone the repository

git clone https://github.com/Kishore2005-Tech/engagement-invitation.git

2. Navigate to the project

cd engagement-invitation

3. Install dependencies

npm install

4. Start the development server

npm run dev

5. Open in your browser

http://localhost:3000

📦 Build for Production

To generate an optimized production build:

npm run build

To preview the production build:

npm run preview
